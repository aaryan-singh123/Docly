Docly – Smart Clinic Reception & Patient Management System

Docly is a modern and professional clinic reception management system designed to simplify daily hospital and clinic operations. It helps receptionists and administrators manage patient registration, doctor appointments, consultation history, payments, and daily workflow in one organized dashboard.

The system is built with a clean and responsive UI using HTML, Tailwind CSS, JavaScript, FontAwesome, and SweetAlert2, providing both desktop and mobile compatibility with smooth animations and dark mode support.

Project Purpose

The main goal of Docly is to reduce manual paperwork and improve efficiency at the reception desk of hospitals, clinics, and medical centers. Instead of maintaining physical registers, patient records are stored digitally using LocalStorage, making data management faster, safer, and easier.

This project is especially useful for hospitals, small clinics, medical consultation centers, doctor chambers, and reception desk operations.

Main Panels / Screens

1. Intro Screen

A startup splash screen with the Docly logo animation for professional branding and smooth user experience.

2. Authentication Screen

Secure login page for authorized personnel only with role-based access control.

3. Dashboard Panel

The main control center showing Total Patients, Pending Patients, Completed Consultations, Daily Revenue, Live Patient Queue, and Quick “Mark Done” feature for consultation completion.

This helps staff monitor the entire day’s workflow efficiently.

4. New Patient Registration Panel

Used for registering new patients with auto-generated Unique Token ID, Full Name, Age, Phone Number, Address, Doctor Selection, Consultation Fees, Payment Method (Cash / UPI), and Transaction ID for UPI.

After registration, the patient is automatically added to the visit queue.

5. Search & History Panel

Advanced patient search system where users can search by Name, Phone Number, and Unique ID.

It also displays full patient profile, complete medical visit history, consultation timeline, payment records, and doctor visit history.

6. Quick Visit Modal

Allows adding a new visit entry for an existing patient without re-registering them.

This is useful for repeat patients returning for consultation.

7. Settings Panel

Includes Dark Mode Toggle, Doctor Management System, Add New Doctors, and Remove Existing Doctors.

This makes the system flexible for different clinic requirements.

8. Admin Panel

Visible only for admin login, providing higher-level management access and administrative control.

Why This Project

Traditional clinic reception systems are often slow, paper-based, and difficult to manage. Docly solves this by creating a digital smart workspace where reception tasks become faster, more accurate, and more professional.

It improves patient handling speed, record management, staff productivity, revenue monitoring, doctor scheduling, and overall clinic efficiency.
